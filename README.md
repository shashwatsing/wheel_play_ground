# Wheel–leg playground

Interactive single-wheel simulator: design a wheel (feet, coverage, curvature, anchor, tilt), design the ground (block field with
height A, width w and edge sharpness β; step; stairs; pit; ramp; flat), and drive it. Open `index.html` in a browser, or visit the
GitHub Pages link for this repository.

2D Box2D model (planck.js 1.0.6, MIT licence, included in the page) of the single-wheel rig from the MuJoCo study: results are close
to the study's but not identical, and its random terrains are not the study's terrains.
